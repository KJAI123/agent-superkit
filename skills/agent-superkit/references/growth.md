# 增长与取证

1. 选一个真实问题。技术入口失效时先查匿名 GET、重定向、正文、canonical、robots、索引指令和 sitemap；需要渲染时再用浏览器。模板改动核源、样本、线上回读。站点归属未知时先核归属。
2. 业务内容用官方原始来源，记核验时刻、适用资格、原单位、时间边界和未知项。价格、一次性优惠、周期、独立配额和共享池分别核对。普通网页可达与权益仍有效分别留证。
3. GEO 用固定题组和可复验的市场、语言、平台及搜索模式。回答、拒绝、登录、挑战、搜索未确认单列。分别记录提及、推荐、实际引用 URL 和事实准确性。引用捕获后可再回读目标页面。
4. 上线后用授权的一方指标，按时区、设备、渠道和 URL 比较可比窗口。Search Console 的 Web 指标、Bing AI 引用、引荐会话和业务转化各按源口径记录。已知无数据时保留未知。
5. 公开投稿只用目标渠道明示允许的形式。收到回执表示提交，实际来源页公开带正确 href 才记外链。先去重站点与渠道。合规送达、真实询单和成交分别回读。

已有 `seo-geo-ops`、`growth-traffic-ops` 或 Shopify 业务技能时沿用相应项目的证据格式和负责人。
