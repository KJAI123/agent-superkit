# 跨 Agent 协作

新任务先查现有项目、原生会话、负责人、授权和账号额度。用可公开复核的目标描述一项任务，给任务 ID、独立目录、冲突文件或渠道、期望交付和验收条件。同一来源文件或外部渠道只有一位当前写入负责人。

派发涉及通用 AI 工具的任务时，附 [GitHub 发布版](https://github.com/KJAI123/agent-superkit/tags) 的标签及需要的模块名，优先用已同步的本机副本。无法加载本机技能的 Agent 可直接读该标签的模块说明；无法联网或没有所需工具时，由有权限的同伴调用并回传结果。

有 `agent-workbench` 时，使用 `list`、`skills`、`find <能力>`、`plan <能力> --project <项目>` 和 `tasks <项目>`。用其既有 `request`/ `inbox` 做申请和派发。看板记录负责人；执行者写自己的证据。任务文件路径和哈希回读后分别标记收到、验收、采用、上线。共享文件夹需要现有会话或约定的检查入口推进。模型和额度采用平台实时回读，不并行消耗同一任务的未知计费池。

## 盘点入口

- Codex 有桌面历史工具时按来源、宿主、活跃/归档分页。摘要供定位，正文按任务需要读取。
- OpenCode 用 `opencode session list --format json` 查看当前项目顶层会话。跨目录、归档与子会话使用当前原生会话接口和实际项目目录。
- OpenClaw 用 `openclaw sessions list --all-agents --limit all --json` 查看其已配置 Agent 的会话。需导出单项时查当前 CLI 支持和脱敏范围。
- ZCode、OpenDesign 以及其他桌面客户端优先用项目侧栏、真实会话和已有交接回执。只有工具实读后才报载入、运行、覆盖或完成。

无共享工作台时，用隔离任务目录和独立交接文件传递已脱敏的状态、路径、SHA-256、验收日志及接收方。
